### 🌟 Featured Project: [Stream Player Pro (Link_To_Play)](https://github.com/Link-To-Play/Link_To_Play)

A zero-dependency, ultra-responsive HTML5 streaming web player optimized for modern browsers and mobile touch screens.

* 🎬 **Universal Format Playback:** Direct streaming for `.mp4`, `.mkv`, and web-compatible codecs with instant stream URL loader.
* 🎛️ **VLC-Style Edge HUDs:** Responsive vertical volume & brightness overlay HUDs with keyboard `<kbd>↑</kbd>/<kbd>↓</kbd>` shortcuts.
* 📐 **Screen Fit & Aspect Ratio Control:** One-click toggle between **Fit**, **Crop/Fill**, **Stretch**, **16:9**, **21:9 (Ultrawide)**, and **4:3**.
* ⚡ **Cloudflare Workers Proxy:** Built-in streaming reverse proxy bypassing upstream CORS headers for external streaming links.
* 🎨 **Theme & Visual Aesthetics:** Frosted-glass navigation, live resolution status indicators, and SVG loading animations.
